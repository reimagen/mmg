# MMG.aDNA — team context graph for GPT Live MMG (optional)

Plain markdown in git. Nothing to install: read it on GitHub, edit a file, push.
Obsidian or Claude Code make it nicer, never required. Use what helps, ignore the rest.

- `STATE.md` — where the build is right now (one screen)
- `what/prd.md` · `what/context/context_system_scope.md` — the PRD and the memory-API contract
- `what/decisions/decisions.md` — D1–D10, locked; add a row, don't reopen
- `who/team.md` — roster and lanes
- `how/templates/` — three 1-minute forms if you want them: AAR (5 lines), coordination
  note (`urgency: info|warning|blocking`), decision record

Code lives in `github.com/reimagen/mmg` (nested at `what/mmg/`, not tracked here).
